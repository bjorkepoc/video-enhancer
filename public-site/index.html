Privacy notice

The page sends the public link you submit to a minimal Cloudflare Pages Function. The Function fetches only supported public pages, returns short-lived source-media links, and does not intentionally persist the submitted URL or media. For TikTok's signed video CDN, it may replay anonymous platform session headers inside one request; they are discarded and never set in your browser.

Cloudflare, the source platform, its media CDN, and your network provider may process ordinary connection data such as IP address and browser information under their own terms. The application does not enable first-party analytics or application logging. Cloudflare and other infrastructure providers may retain security and service logs under their own policies.

The application derives a salted, short-lived in-memory rate-limit key from the connection IP address. It does not store the raw address itself. Submitted links may still appear in infrastructure request data controlled by Cloudflare or the source provider.

Previewing or processing media transfers bytes into temporary browser memory or cache. A file appears in Downloads only when you choose a download action. Closing or reloading the page clears in-memory results.

Optional enhancement starts only after separate consent. The FFmpeg WebAssembly engine is fetched from the version-pinned jsDelivr CDN, so jsDelivr receives an ordinary network request. Source media and output are processed inside your browser, not by our Worker.

The visible sponsor placements are static and tracking-free. The application sets no first-party browser cookies, localStorage, IndexedDB, advertising identifiers, or personalized-ad scripts. This notice and a suitable consent flow must be updated before any ad network or analytics is enabled.
